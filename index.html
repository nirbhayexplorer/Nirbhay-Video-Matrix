Documentation

How Nirbhay Video Matrix retrieves and displays data

Overview

This build of Nirbhay Video Matrix is a single self-contained HTML file with no server component. It calls the YouTube Data API v3 directly from your browser, using a key configured by whoever distributed this file. It parses a video URL, requests the videos and channels resources, and renders the fields those responses return.

Supported URL formats

  • https://www.youtube.com/watch?v=VIDEO_ID
  • https://youtu.be/VIDEO_ID
  • https://www.youtube.com/shorts/VIDEO_ID

API resources requested

To minimize quota usage, only the parts actually rendered in the interface are requested:

  • videos.list with part=snippet,contentDetails,statistics,status
  • channels.list with part=snippet,statistics

About the configured key

Because this file has no backend to keep a secret on its own, the API key it uses is embedded directly in the page's source code. Anyone who views this page's source can see that key. This is a deliberate tradeoff made so the file can be opened and used immediately, by anyone, with no setup — see the Privacy page for what that means in practice, and the API Information page for how usage of that shared key is affected.

Video age calculation

Age is computed with calendar-accurate arithmetic between the current time and the video's publishedAt timestamp — accounting for actual month lengths and leap years rather than averaging days per month — and is broken into years, months, days, hours, minutes and seconds. The on-screen counter re-runs this calculation once per second.

Thumbnails

Thumbnail URLs and dimensions come directly from the snippet.thumbnails object in the API response; no thumbnail URL is constructed or guessed by this tool. Downloading a thumbnail fetches the image in your browser and saves it as a file; if your browser's security settings block reading the image bytes directly (this can happen depending on how the image host is configured), the tool opens the full-size image in a new tab instead so it can still be saved manually.

Rate limiting and input handling

The Analyze button is disabled for the duration of a request to prevent duplicate submissions, and the URL field is validated before any network request is made. A malformed or unsupported URL never reaches the network layer at all — it is caught and reported at the input stage.

How theme selection works

The theme control in the header cycles between Dark, Night, and Day. The choice is stored in your browser's local storage under a single key so it persists between visits, and is applied by setting a data-theme attribute on the page's root element; all colors in the interface are defined as CSS custom properties that respond to that attribute, so no page reload is needed when switching.

Copy system behavior

Every Copy control uses the browser's native Clipboard API. On success, the button's label temporarily changes to "Copied" and reverts automatically after a short interval; if the browser denies clipboard access — which can happen in some embedded or non-secure contexts — the button reports that copying was not possible rather than failing silently.

Reading the Technical Details panel

Each result includes an expandable Technical Details section containing the exact videos and channels API resources used to populate the page, formatted as readable JSON. This is intended for anyone who wants to verify precisely where a displayed value came from, or who wants to see fields the interface does not surface directly. A Copy JSON control copies this entire payload.

Running this application

This is a single HTML file with everything — markup, styling, and logic — inline. Opening it in any modern browser is enough to use it; there is nothing to install and no server to start.

Browser support

The frontend relies on the fetch, Clipboard, and Intl.DateTimeFormat APIs, all standard in current versions of Chrome, Firefox, Safari, and Edge.

Extending this tool

Because the interface, the URL parser, the age calculator, and the API-calling logic are kept as clearly separated functions within the file, adding a new displayed field generally means adding one line to the API request's part parameter and one corresponding element to the results template, without needing to change unrelated sections such as the theme system or the copy system.

Limitations

What this tool can and cannot show you

Scope of available data

Nirbhay Video Matrix can only display information that the YouTube Data API v3 legitimately returns for a given video and channel. It does not access, infer, bypass, or reconstruct any information beyond that. If a value is not present in the API response, the interface will say so explicitly rather than guessing, averaging, or filling in a plausible-looking substitute. This is a deliberate design choice: a blank or estimated figure is worse than no figure at all, because it can be mistaken for real data.

Every field rendered in the analysis card, the statistics dashboard, the channel panel, and the Technical Details JSON viewer traces back to one of two API calls — a videos.list request and a channels.list request. Nothing shown in the interface is derived from any other source, scraped from the public YouTube website, or cached from a prior request to a different video.

Fields that may be unavailable

  • Like count — creators can hide this from the public API response since YouTube introduced the option to conceal dislike counts and, in some account configurations, like counts as well.
  • Comment count — unavailable if comments are disabled on the video, or if comments are held for review and not yet published.
  • Subscriber count — some channels hide this figure; when hidden, the API returns a flag indicating the count is suppressed rather than a number, and this tool reflects that as "Hidden by channel" rather than zero.
  • Category — not always present depending on how the video was uploaded, and even when present it is returned only as a numeric category ID rather than a resolved category name, since resolving that name requires an additional API call this tool does not make in order to conserve quota.
  • Channel description and channel thumbnail — a channel can leave its description empty or restrict its avatar, in which case the corresponding field will be blank in the API response.
  • Maximum-resolution thumbnail — the 1280×720 maxres thumbnail is only generated for videos uploaded in sufficiently high resolution; older or lower-resolution uploads may only have "High," "Medium," and "Default" sizes available.

Where a field is missing from the API response, the interface states Not available rather than estimating or fabricating a value. This applies uniformly across the statistics dashboard, the channel panel, and every copyable field in the analysis card.

Videos that cannot be analyzed

  • Private videos — not retrievable by an API key that isn't the video owner's own authenticated request; a private video will return an empty result set as though the video ID does not exist.
  • Deleted or removed videos — including videos removed for a Terms of Service violation, a copyright claim, or at the uploader's own request.
  • Unlisted videos — retrievable by direct video ID in most cases, since unlisted is not the same access level as private, but this can vary.
  • Region-restricted videos — a video blocked in the region associated with the requesting API key may return incomplete metadata or fail outright, depending on how the restriction was configured by the rights holder.
  • Age-restricted videos — may return limited metadata, since some fields are only available to authenticated, age-verified requests rather than a general-purpose API key.
  • Livestreams and premieres — a video that is currently live or scheduled as a premiere may return statistics that are still in flux, partial duration data, or a status that differs from a normally published upload.

Numerical accuracy and timing

View, like, and comment counts returned by the API are not updated in real time on YouTube's side; YouTube itself applies some smoothing and delay to these figures before they are exposed through any interface, including the API. A number shown here reflects what the API returned at the moment of the request, not necessarily the count visible on youtube.com at that exact same instant.

The video age calculation is accurate down to the second relative to your device's system clock and the publishedAt timestamp returned by the API. If your device's clock is incorrect, the displayed age will be off by the same amount, since this tool has no independent source of the current time.

API quota

The YouTube Data API v3 enforces a daily quota per key, measured in quota units rather than in a simple request count — different endpoints and parts consume different amounts of quota. Once a key's quota is exhausted, every request made with that key fails until the quota resets on Google's schedule, regardless of how this tool is used or how the request is structured. This tool does not provide, promise, or simulate unlimited API access, and it does not maintain its own pool of shared quota on your behalf.

Channel Analyzer quota cost

Looking up a channel by its ID, handle, or URL is inexpensive. Looking a channel up by a plain name it doesn't recognize as a handle falls back to YouTube's search endpoint, which costs substantially more quota per request than any other call this tool makes — so channel name search should be used sparingly, especially on a shared key. The uploads list is fetched through the channel's uploads playlist rather than search, which keeps browsing a channel's videos inexpensive regardless of how many are loaded.

No privacy bypass

This tool does not circumvent YouTube's privacy settings, age restrictions, regional restrictions, monetization status, or any other access control enforced by YouTube or by the uploader. It surfaces exactly what the YouTube Data API is willing to return for the credentials used to query it — nothing more, and nothing that a developer with the same key and the same public API documentation could not already retrieve directly.

What this tool is not

Nirbhay Video Matrix is a metadata inspector, not an analytics platform, a download service for video files, or a monetization estimator. It analyzes one video or one channel at a time, on request, and does not run in the background, does not poll YouTube periodically, and does not build any historical record of a video's or channel's performance over time.

Privacy Policy

What happens to your data when you use this application

Introduction

This Privacy Policy describes how Nirbhay Video Matrix handles information when you use it. We designed the application around a simple principle: it should only touch the minimum information necessary to perform the task you asked it to perform, and it should be transparent about exactly where that information goes.

What information is processed

The application processes one piece of information you provide directly: the YouTube video URL you paste into the analyzer. Because this file has no backend, that URL is used only to construct a request sent directly from your browser to the YouTube Data API. You are never asked for, and never need to provide, an API key of your own — this file already includes one, configured by whoever distributed it to you.

YouTube URL processing

The URL you paste is parsed entirely locally in your browser using pattern matching to extract an 11-character video ID. It is never transmitted to any destination other than the YouTube Data API request itself, and it is not stored beyond the current browser session unless your browser's own history or autofill retains it independently of this application.

API requests

Requests to the YouTube Data API are made directly from your browser to Google's servers. Google's handling of that request is governed by Google's Privacy Policy and the YouTube API Services Terms of Service, neither of which is controlled by this application.

Clipboard functionality

Copy controls throughout the interface use your browser's native Clipboard API to copy text you explicitly requested to copy — such as a video title, a description, an ID, a thumbnail URL, or the raw JSON payload. This action happens entirely on your device; no clipboard content is transmitted anywhere by this application, logged, or made available to the application's operator.

Cookies and local storage

This application does not set cookies. It uses your browser's local storage for exactly one optional, functional purpose: remembering your selected color theme (Dark, Night, or Day) across visits. This is stored on your own device only, is never transmitted anywhere, and can be cleared at any time by clearing this page's data in your browser settings.

Analytics and tracking

This application does not include any analytics scripts, advertising trackers, session recording tools, or third-party tracking pixels of any kind. Your usage of the application is not measured, profiled, or reported to the application's operator.

Data retention

Because there is no backend server associated with this file, it does not retain, log, or store any video URLs, analysis results, or usage history beyond what your own browser chooses to keep locally under the terms described above.

API Information

How the YouTube Data API v3 layer behind this application works

Configured, not requested

Nirbhay Video Matrix uses a single YouTube Data API v3 key embedded in this file by whoever distributed it. You are never asked to provide, paste, or manage an API key of your own — every analysis request uses that same configured key.

What gets called

  • GET https://www.googleapis.com/youtube/v3/videos — requested directly from your browser with part=snippet,contentDetails,statistics,status for the video ID extracted from your URL.
  • GET https://www.googleapis.com/youtube/v3/channels — requested directly from your browser with part=snippet,statistics for the video's channel ID.

Quota

Because everyone using this file shares the same configured key, the daily quota is shared across all usage, not allocated per person. Heavy use — by you or by anyone else this file was shared with — can exhaust that shared quota, after which analysis will fail for everyone until the quota resets on Google's schedule.

No rate limiting

Because this is a single client-side file with no server to enforce limits, there is no rate limiting on requests beyond what your own browser and Google's own API throttling apply. Please be considerate with how often and how widely you use or share this file, since its quota is shared.

Failure handling

If the configured key becomes invalid, is not enabled for the YouTube Data API v3, or the quota is exhausted, this interface shows a plain, human-readable message rather than the raw error Google's API returns.
